<h1>Валюта-профи - Корпоративный сайт с конвертером валют</h1>

<h2>Описание проекта</h2> <p><strong>Корпоративный веб-сайт для компании "Валюта-профи"</strong> с системой управления контентом, конвертером валют и административной панелью.</p><h2>🚀 Основные возможности</h2> <ul> <li><strong>📰 Управление статьями</strong> - Добавление, редактирование и публикация статей через административную панель</li> <li><strong>💬 Система отзывов</strong> - Публикация и модерация отзывов клиентов</li> <li><strong>💱 Конвертер валют</strong> - Реальный курс валют через внешний API с функцией конвертации</li> <li><strong>🎨 Рекламные баннеры</strong> - Управление рекламными материалами на сайте</li> <li><strong>🔐 Административная панель</strong> - Полный контроль над контентом сайта</li> <li><strong>📱 Адаптивный дизайн</strong> - Современный интерфейс с навигационными кнопками</li> </ul><h2>🏗️ Технологический стек</h2><h3>Backend</h3> <ul> <li><strong>FastAPI</strong> - Современный, быстрый веб-фреймворк для Python</li> <li><strong>PostgreSQL</strong> - Надежная реляционная база данных</li> <li><strong>SQLAlchemy</strong> - ORM для работы с базой данных</li> <li><strong>Pydantic</strong> - Валидация данных</li> </ul><h3>Frontend</h3> <ul> <li><strong>JavaScript (ES6+)</strong> - Интерактивность на стороне клиента</li> <li><strong>HTML5 & CSS3</strong> - Современная верстка</li> <li><strong>Fetch API</strong> - Взаимодействие с backend</li> <li><strong>Адаптивный дизайн</strong> - Поддержка мобильных устройств</li> </ul><h3>Внешние сервисы</h3> <ul> <li><strong>API курса валют</strong> - Получение актуальных курсов валют</li> </ul>
